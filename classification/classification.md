# Классификация: модель + harness (связка как единый класс)
## 1. Цель
Многоклассовая классификация объекта (трейс агента) по метке **`model × harness`** (связка = один целевой класс).
Распределение классов неравномерное → метрики и обучение настраиваются под дисбаланс.

## 2. Группы признаков и их обработка

| Группа | Что это | Обработка | Модель-энкодер |
|---|---|---|---|
| **T — текст** | сырые тексты трейсов / промптов / вывода | эмбеддинги через BERT / BM25-фичи; PCA до 50–100 компонент (только для текста) | sentence-transformer + LightGBM |
| **X — таксономия** | цепочки стандартизированных действий (10 классов) | метки как категориальные (CatBoost, без OHE) + TF-IDF по n-граммам переходов | CatBoost |
| **G — графы** | граф трейса: временные + смысловые рёбра | графовые статистики (степени, центральности, мотивы, диаметр) + опционально node2vec/graph2vec с пулингом | LightGBM / GNN (если хватает данных) |
| **P — процедурные / табличные** | числовые фичи из процедурной обработки | без масштабирования (деревья инвариантны); выбросы — winsorize по необходимости | LightGBM / CatBoost |

**Правило:** группы не склеивать в один плоский вектор. Обрабатывать раздельно → объединять на уровне предсказаний.

## 3. Масштабирование и кодирование
- Числовые (G, P): **не масштабировать** для бустинга. StandardScaler — только если финальный мета-классификатор линейный (LogReg).
- Категориальные (X): **не OHE** → CatBoost с категориальными признаками.
- Текстовые эмбеддинги: **PCA / Sparse PCA / Boruta** для снижения размерности.

## 4. Отбор признаков
1. Обучить базовую модель на каждой группе отдельно (CV).
2. Посчитать **SHAP** внутри группы.
3. Отобрать топ-N по SHAP (по группе), проверить на CV.
4. Кросс-групповой отбор — **не делать** до этапа fusion.

## 5. Объединение (late fusion / stacking)
1. Для каждой группы — своя модель, **out-of-fold** предсказания (вероятности классов).
2. Мета-классификатор на OOF-вероятностях: LogReg (L2) или XGBoost.
3. Опционально добавить 1–2 ключевых исходных признака (не все).
4. Пороги для редких классов настраивать на уровне мета-модели.

## 6. Дисбаланс классов
- Loss: **focal loss** или взвешенная CE (веса ~ обратны частотам).
- Данные: Borderline-SMOTE — **только** для низкоразмерных табличных групп (P, G-статистики). Не применять к текстовым эмбеддингам и сырым последовательностям.
- Валидация: **стратифицированная CV** (редкие классы в каждом фолде).

## 7. Метрики
- Основная: **macro-F1**.
- Дополнительно: balanced accuracy, per-class recall (особенно для редких связок).
- Accuracy — только справочно.

## 8. Сетка экспериментов (ablations)
| Ось | Варианты |
|---|---|
| Набор групп | T, X, G, P, T+X, T+G, X+G+P, все |
| Отбор признаков | без отбора / SHAP-top-N / PCA / Boruta |
| Модель на группу | LightGBM, CatBoost, (GNN для G) |
| Fusion | early (concat) vs late (stacking) |
| Дисбаланс | none / class weights / focal / +SMOTE (только P,G) |

## 9. Артефакты пайплайна
- `features/{T,X,G,P}` — отдельные матрицы.
- `oof_preds/{T,X,G,P}` — OOF-вероятности.
- `meta_model` — мета-классификатор.
- `report` — macro-F1 по фолдам, per-class метрики, SHAP-топ по группам.
